## 완료된 작업

### 백엔드 인프라
- Prisma 스키마(14개 엔티티) + PostgreSQL 초기 마이그레이션, 루트 `docker-compose.yml`(`monolog-postgres` 컨테이너)
- `FirebaseAuthGuard`(Firebase ID 토큰 검증) + `AppUserGuard`/`@CurrentAppUser()`(firebaseUid → 내부 `User` 레코드 변환, 전 도메인 모듈 공용)
- 전역 `ValidationPipe`, Prisma 드라이버 어댑터(`@prisma/adapter-pg`) 구성

### 도메인 모듈 (Controller → Service → Prisma 구조)

| 모듈 | 상태 | 핵심 기능 |
|---|---|---|
| `user` | ✅ | 프로필 upsert/조회 |
| `friend` | ✅ | 친구 요청/수락/거절, 친구 목록, 언프렌드. `FriendRequest`(방향성 있는 요청)/`Friendship`(대칭 관계) 테이블 분리 완료 |
| `group` | ✅ | 그룹 생성/초대코드 가입/탈퇴, `isMember()` 공용 export(diary·qna가 재사용) |
| `diary` | ✅ | CRUD, privacy scope(private/public/group), 그룹 공유, 오늘의 프롬프트 조회 |
| `qna` | ✅ | 그룹 질문/답변, 48시간 소프트 삭제, 질문/답변 북마크 |
| `chat` | 🟡 뼈대만 | WebSocket 게이트웨이 스캐폴딩만 있고 실제 메시지 처리 로직 없음 |

- 전체 unit 테스트(16 스위트) 그린, 실제 Postgres 기동 후 부팅+curl 스모크 테스트로 라우트/인증 가드 정상 동작 확인

### 문서 구조 정리
- `docs/decisions/` — 실제 갈림길이 있었던 기술적 결정만 (예: CJS vs ESM)
- `docs/logs/` — 작업 단위별 기록 (이 파일 포함 4개)
- `docs/erd/` — ERD 원본 SQL export + 엔티티 정리 문서
- `docs/planning/` — 기획서 v1~v3, 버전별 검토 이슈
- `docs/study/` — 개인 학습용 메모 (`.gitignore` 처리, 저장소에 커밋 안 됨)
- `backend/README.md`를 NestJS 기본 템플릿에서 실제 프로젝트 셋업 가이드로 재작성

### Git
- `main` 브랜치에 총 7개 커밋, 전부 push 완료 (최신: `35dbe29 Split Friend into FriendRequest and Friendship`)

## 앞으로 진행해야 할 작업

### 🔴 우선순위 높음 — 백엔드 인증 실동작 검증
- `backend/.env`의 `FIREBASE_PROJECT_ID`/`FIREBASE_CLIENT_EMAIL`/`FIREBASE_PRIVATE_KEY`가 비어있음 — Firebase 프로젝트 생성 및 서비스 계정 키 발급 필요
- 지금까지는 "토큰 없으면 401 반환"까지만 검증됨. 실제 토큰으로 인증이 끝까지 도는 플로우는 아직 한 번도 확인되지 않음

### 🟡 미구현 영역
- **`chat` 모듈**: 실제 그룹 채팅 메시지 송수신 로직 없음
- **`frontend`**: Next.js 기본 스캐폴드 그대로, 실제 화면(로그인, 일기 작성, 그룹 관리 등) 없음
- **`ai-service`**: FastAPI mock 응답만 존재 (`suggest_title` 등이 하드코딩된 가짜 값 리턴)

### 🟢 의도적으로 미룬 스코프 (백로그, 필요 시 추가)
- 그룹 삭제 API (cascade 미정의로 FK 위반 위험)
- 그룹 초대코드 재발급/갱신 API
- 질문/답변 "내 북마크 목록" 조회 API
- `UpdateDiaryDto`로 `privacyScope`를 `'group'`으로 변경하는 기능 (그룹 공유 변경은 별도 엔드포인트 필요)

### 🟢 테스트 커버리지
- e2e 테스트 아직 없음 (현재는 단위 테스트만 존재)
