# 프론트엔드 로그인 화면 구현

- 범위: `frontend/src/app/login/`, `frontend/src/lib/firebase.ts`, `backend/src/main.ts`
- 목표: Firebase 인증이 실제로 붙은 첫 프론트엔드 화면 구현 (로그인/회원가입 → 백엔드 프로필 등록 → 홈 리다이렉트)
- 관련 문서: [Firebase 연결 및 Postman 검증](./05-Firebase%20연결%20및%20Postman%20검증.md)

## 진행 내용

1. `frontend`에 `firebase` 패키지 설치 (`npm install firebase`)
2. `frontend/src/app/login/page.tsx` 신규 작성
   - 이메일/비밀번호 단일 폼으로 로그인·회원가입을 한 번에 처리: `signInWithEmailAndPassword` 시도 → 실패(`auth/user-not-found`, `auth/invalid-credential`) 시 `createUserWithEmailAndPassword`로 폴백
   - 성공 시 `getIdToken()`으로 토큰을 받아 `POST /user`(백엔드)로 프로필 upsert, 이후 `router.push('/')`로 이동
   - 별도 로그인/회원가입 화면 분리, 세션 유지(`onAuthStateChanged`), 보호된 라우트는 이번 범위에서 제외 — 화면이 여러 개로 늘어날 때 다시 고려
3. 실제 브라우저(Claude in Chrome)로 end-to-end 테스트

## 발견한 버그: CORS 미설정

- **증상**: 브라우저에서 `POST /user` 호출 시 `Failed to fetch`. 네트워크 탭 확인 결과 `OPTIONS /user → 404`(프리플라이트 실패)
- **원인**: `backend/src/main.ts`에 CORS 허용 설정이 아예 없었음. Postman으로 테스트할 때는 브라우저의 CORS 정책이 적용 안 돼서 여태 드러나지 않았던 문제 — 프론트엔드(브라우저)에서 처음 호출해보고서야 발견됨
- **해결**: `app.enableCors({ origin: process.env.FRONTEND_URL ?? 'http://localhost:3000' })` 추가

## 검증

- Claude in Chrome으로 `http://localhost:3000/login` 접속 → 이름/이메일/비밀번호 입력 → 제출
- 네트워크 탭에서 `accounts:signUp`(Firebase) → `POST /user`(`201`) → `/`로 리다이렉트까지 실제로 확인
- 콘솔에 뜬 hydration mismatch 에러는 `cz-shortcut-listen="true"` 속성 때문 — ColorZilla 브라우저 확장이 하이드레이션 전에 DOM을 건드려서 생기는 것으로, 코드 문제 아님 (참고: [Next.js/Firebase 로그인 디버깅](../study/nextjs-firebase-로그인-디버깅.md))

## 현재 상태

- 디자인 없음 (Tailwind 기본 유틸리티로 카드+폼만 배치)
- 로그인 후 세션 유지 로직 없음 (새로고침하면 다시 로그인해야 함 — 아직 구현 안 함)
- 다음 프론트 작업은 일기/그룹 화면 (REST 기반이라 기존 백엔드로 바로 연동 가능). `chat`은 WebSocket이라 별도 클라이언트 연결이 필요해 뒤로 미룸 — 프론트에서 채팅 화면을 만들 차례가 됐을 때 백엔드 `chat` 모듈도 같이 구현하기로 함
