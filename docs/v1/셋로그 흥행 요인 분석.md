## **`셋로그(Setlog) 흥행 요인 분석`**

2026년 상반기 앱스토어 1위를 기록한 브이로그/일상 공유 앱 '셋로그'의 성공 요인 정리 및 다이어리 프로젝트에 대한 시사점.

## **`흥행 요인`**

### 1. 극단적으로 낮은 진입장벽

긴 글 작성이나 영상 편집이 전혀 필요 없이, 알림이 울리는 순간 눈앞의 장면을 2초 내외로 짧게 찍어 올리기만 하면 끝. "완성도"를 고민할 필요가 없어 콘텐츠 제작 부담이 거의 0에 가깝다.

### 2. AI 시대의 역설 — "날것"의 희소성

AI로 완벽한 편집/보정이 너무 쉬워진 시대이기 때문에, 오히려 편집 없는 진짜 순간이 희귀해지고 매력적으로 느껴진다. 인스타그램식 "잘 꾸민 피드"에 대한 피로감의 반작용.

### 3. 동기화된 기록 구조 (핵심 차별점)

단순히 각자 기록을 올리는 게 아니라, 친구/그룹이 같은 시간대에 동시에 알림을 받고 각자의 순간을 기록한다. 서로 다른 공간에 있어도 "하루를 함께 완성한다"는 유대감·공동체 경험을 제공하며, 다른 브이로그 앱과의 근본적 차이로 꼽힌다.

### 4. 저자극 콘텐츠 + SNS 피로 해소

Z세대가 인스타그램의 "보여주기식" 피로감에서 벗어나 꾸밈없는 일상을 원한다는 니즈를 정확히 겨냥.

### 5. 광고비 없는 자연 성장 (바이럴 구조)

셋로그팀 인터뷰에 따르면 별도 마케팅비 없이 앱스토어 1위를 달성했는데, "함께 찍어야 완성되는" 구조 자체가 친구 초대를 필수화하는 바이럴 루프를 내장하고 있기 때문이다.

## **`다이어리 프로젝트에 대한 시사점`**

| 셋로그 성공 요인 | 다이어리 기획서 현황 |
|---|---|
| 낮은 진입장벽(2초 기록) | 텍스트 중심 → 오히려 진입장벽이 높을 수 있음 (긴 글 작성 부담) |
| 동기화/공동 기록 경험 | 그룹 공유는 있지만 "동시성"·"공동 완성" 요소는 없음 |
| 날것/진정성 소구 | AI가 제목·음악·일러스트까지 대신 만들어줌 → 방향이 반대(가공·보조 강화) |
| 바이럴 내장 구조 | 친구 초대를 유도하는 메커니즘이 명시되어 있지 않음 |

셋로그는 "쉬움·즉시성·동시성"으로, 다이어리 기획서는 "깊이·감성·개인 기록"으로 서로 다른 축을 노리고 있어 직접 경쟁보다는 포지셔닝 차별화로 볼 수 있다. 다만 온보딩 진입장벽(첫 일기 작성까지의 심리적 허들)을 낮추는 장치나, 그룹 공유 기능에 약한 "함께 쓰는 순간" 같은 요소는 참고할 만하다.
