## **`PROJECT TOPIC`**

‘Instagram’과 같이 사진 중심 SNS의 피로감을 줄이고, 텍스트와 진솔한 기록에 집중하며 AI 감성 기능과 그룹 별 공유 권한을 제공하는 감성 소셜 다이어리 서비스

## **`PROJECT OVERVIEW`**

- 기획 배경 : 기존 ‘인스타그램’ 등 화려한 이미지 중심 SNS에서 벗어나, 글과 기록 본연에 집중할 수 있는 공간을 제공하고자 함. 다만 텍스트 중심 기록은 진입장벽이 높다는 한계가 있어, '셋로그(Setlog)' 등 저부담 기록 앱의 흥행 요인(낮은 진입장벽, 그룹 동기화 기록 경험)을 참고하여 보완함.
- 핵심 컨셉 :
    - 인스타그램 형태의 익숙한 피드 레이아웃
    - 텍스트 중심의 기록 + 보조적 미디어(사진/영상) 첨부
    - 세분화된 프라이버시/공유 설정
    - AI를 활용한 감성 케어 및 요약 기능
    - **낮은 진입장벽의 초간단 기록 옵션** (원라인 모드 / AI 질문 프롬프트)
    - **그룹 동기화 기록**을 통한 공동체 경험 제공 (위클리 체크인)

## **`CORE FEATURES`**

### 1. 일기 작성 및 미디어 첨부 (Contents)

- 텍스트 중심 작성 : 짧은 메모부터 긴 일기까지 글 중심으로 자유롭게 작성.
- 미디어 첨부 : 글의 감성과 추억을 기억하는데 보완할 수 있는 이미지 및 짧은 동영상 업로드 지원.
- **⚡ 원라인 모드 (Quick Log):**
    - 홈 피드 상단 고정 입력바에서 이모지 선택 + 한 줄 텍스트만 남겨도 정식 일기로 카운트(연속 기록일수 스트릭에도 반영)
    - **이어쓰기**: 아침에 남긴 원라인을 이후 다시 열어 내용을 덧붙여 긴 일기로 발전시킬 수 있음 — "가볍게 시작해서 원하면 깊이 쓰는" 흐름으로 진입장벽을 낮추는 핵심 장치
- **💬 AI 질문 프롬프트 (Guided Entry):**
    - 매일 지정 시간에 짧은 질문(예: "오늘 가장 웃겼던 순간은?", "오늘 누군가에게 고마웠던 일은?")을 푸시 알림으로 발송, 답변만 하면 일기 완성
    - MVP 단계는 정적 질문 뱅크(요일/계절별 로테이션)로 시작, 이후 최근 일기 패턴을 분석한 AI 개인화 질문으로 고도화
    - 질문은 메타데이터로 함께 저장되어 이후 AI 요약 리포트와도 연동 가능

### 2. 세분화된 공유 권한 설정 (Privacy Control)

- 🔒나만보기 (Praivate): 나만 접근 가능한 완전한 개인 비밀 공간
- 👥전체 공유 (Public/Friends): 내 친구 목록 전체에 공개되는 피드
- 👪그룹별 선택 공유 (Group): 특정 모임, 가족, 동아리 또는 친한 친구와 같이 지정한 그룹 멤버에게만 제한적으로 피드 공개

### 3. 그룹 동기화 기록 — 위클리 체크인 (Group Sync)

- 그룹별로 정기 발행(예: 매주 일요일 저녁) 또는 그룹장 수동 발행으로 전원에게 동일 질문을 동시 푸시
- **동시 공개 잠금**: 마감 시간(예: 24시간) 전에는 타인 응답을 볼 수 없고, 본인이 먼저 응답해야 그룹 피드를 열람할 수 있음 — 서로 눈치 보지 않고 솔직하게 기록하게 만드는 장치
- 마감 후 전원의 응답을 그룹 전용 피드에 모아 한 번에 공개, "N명 중 M명 응답 완료" 참여율 표시로 리텐션 및 자연스러운 초대 유도
- 그룹별 체크인 히스토리를 모아보는 아카이브 뷰 제공

### 4. AI 기반 차별화 기능 (AI Integration)

- **🎵 AI 감성 음악 추천:**
    - 작성된 일기의 텍스트와 감정 톤을 AI가 분석
    - 일기 분위기와 잘 어울리는 음악(BGM/곡)을 자동 추천
- **📊 AI 주별 / 월별 회고 요약:**
    - 일주일 또는 한 달 동안 쌓인 일기 데이터를 분석
    - 무슨 일이 있었는지 주요 사건과 감정 흐름을 한눈에 보기 좋게 요약 리포트로 생성
- **📝AI 제목 추천:**
    - AI가 일기 내용을 바탕으로 적절한 제목을 추천해줌
    - 여러가지 옵션을 주고 선택 및 수정가능.
    - 추후 심화 과정으로 AI 커버 일러스트 생성 기능 추가
        - AI 커버 일러스트 생성 기능 상세
            
            사진이나 동영상을 첨부하지 않고 글만 쓴 날, AI가 일기 내용을 분석하여 **어울리는 감성의 수채화/미니멀 일러스트 커버 이미지**를 자동으로 1장 생성해 주는 기능
            
            **개발 포인트**: 이미지 생성 AI API(예: DALL-E, Stable Diffusion 등) 연동 경험과, 생성된 이미지를 클라우드 저장소에 저장하고 캐싱하는 프론트/백엔드 로직을 익힐 수 있다.
            
- **🔒 타임락(Time-Lock) 일기 & 프라이빗 보안 미디어:**
    - "이 일기는 2027년 1월 1일에 공개됩니다"처럼 특정 미래 시점에 지정된 친구나 그룹에게만 열리는 미래 일기/타임캡슐 기능
    - 나중에 클라우드 네트워크에 올릴 때, '나만 보기'나 '타임락'이 걸린 미디어 파일(이미지/영상)에 대해 비인가자가 URL만 복사해서 들어오는 것을 막는 **보안 URL(Presigned URL)** 기법을 적용

## **`TECHNICAL POINT`**

- **프론트엔드 (FE):**
    - 텍스트 피드 중심의 깔끔하고 감성적인 UI/UX
    - 드래그 앤 드롭 미디어 업로드 및 비동기 데이터 처리
    - 홈 피드 상단 고정 원라인 입력바 UI, 이어쓰기 편집 흐름
- **백엔드 (BE) & 데이터베이스 (DB):**
    - 일기별/그룹별 접근 권한을 엄격하게 통제하는 권한 제어(RBAC) 로직
    - 회원, 일기, 그룹, 미디어 간의 효율적인 DB 관계(Relational) 설계
    - 일기 엔티티에 `entry_type(quick/full)` 구분 필드, 질문 프롬프트 메타데이터 연동
    - 그룹 체크인 세션 엔티티 설계(`group_id`, 질문, 시작/마감시간, 공개조건) 및 마감 전 응답 비공개(잠금) 로직 — 기존 RBAC 로직의 연장선에서 구현
    - 정기 알림 발송을 위한 스케줄링 인프라 (푸시 알림, cron/스케줄 잡)
    - LLM/AI API 연동 및 프롬프트 엔지니어링

## **`ROADMAP`**

- **1단계 (MVP):** 회원가입, 텍스트/미디어 일기 작성, 원라인 모드 + 정적 질문뱅크 기반 AI 질문 프롬프트(진입장벽 최소화 우선 검증), 3단계 공유 권한(나만보기/전체/그룹) 구현, AI 제목 추천, 타임락 일기 & Presigned URL 보안 미디어(권한 설계와 함께 구축)
- **2단계 (그룹 동기화):** 그룹 위클리 체크인 기능(동시 공개 잠금, 참여율 표시, 히스토리 아카이브) — 그룹 권한 체계 위에 구축
- **3단계 (AI 연동):** 일기 작성 시 AI 감성 음악 추천 API 연동, AI 질문 프롬프트 개인화 고도화(최근 일기 패턴 기반 질문 생성)
- **4단계 (고도화):** 주별/월별 AI 요약 리포트 생성 기능 추가 및 UI 최적화
- **5단계 (심화):** AI 커버 일러스트 생성 기능 (이미지 생성 API 연동 및 클라우드 저장/캐싱)
