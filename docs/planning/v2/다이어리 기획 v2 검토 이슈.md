## **`검토 배경`**

`다이어리 웹 서비스 기획 v2.md`에 신규 반영한 2가지 기능(⚡ 원라인 모드/AI 질문 프롬프트, 그룹 위클리 체크인)이 기존 기획 항목들과 충돌하거나 정의가 비어있는 지점을 정리한 문서. 각 항목의 "내 결정" 란에 방향을 적어두면 이후 v2 문서에 반영.

## 🔴 실질적 충돌 (해결 필요)

### 1. AI 커버 일러스트 생성 조건 vs 원라인 모드

- **위치**: CORE FEATURES 1번(원라인 모드) / 4번(AI 커버 일러스트 생성)
- **문제**: 일러스트 생성 조건이 "사진이나 동영상을 첨부하지 않고 글만 쓴 날"인데, 원라인 모드(이모지+한 줄)도 이 조건에 그대로 해당함. 가장 저부담으로 설계한 기능이 AI 기능 중 가장 비용이 큰 이미지 생성 API를 매일 트리거할 수 있음.
- **선택지 예시**:
    - a) 원라인 모드는 일러스트 생성 대상에서 완전 제외
    - b) 최소 글자수/조건을 둬서 그 이상일 때만 생성
    - c) 그대로 두되 생성 여부를 사용자가 매번 선택하게 함
- **내 결정**: c를 선택하되, 임시 저장 기능 고려 (유저가 작성 중에 업로드 버튼을 누르지 않고 뒤로가기나 화면을 벗어나려는 시도를 할 경우. 화면에 팝업 경고창으로 임시저장 여부를 물어봄.)

### 2. 그룹 위클리 체크인 vs 프라이버시 설정(나만보기)

- **위치**: CORE FEATURES 2번(Privacy Control) / 3번(Group Sync)
- **문제**: 체크인 응답은 그룹 전체 공개가 전제인데, 일반 일기의 "나만보기" 설정과의 관계가 정의되어 있지 않음. 체크인에 응답한 뒤 나만보기로 바꾸면 어떻게 되는지 불명확.
- **선택지 예시**:
    - a) 체크인 응답은 별도 카테고리로 취급, 개별 프라이버시 설정 불가(항상 그룹 공개)
    - b) 체크인 응답도 일반 일기와 동일한 권한 체계를 따름(나만보기 전환 가능, 단 그룹 참여율 집계에서는 "응답 완료"로만 표시)
- **내 결정**: a

    - b) 문구에서 스트릭 언급을 제거하고 단순 카운트만 유지

## 🟡 철학적 긴장 (v1부터 있었던 문제, v2에서도 미해결)

### 4. "진정성/날것" 지향 vs AI 자동 생성 기능들

- **위치**: PROJECT OVERVIEW(기획 배경) / CORE FEATURES 4번(AI Integration)
- **문제**: 셋로그 벤치마킹 취지 중 "낮은 진입장벽"은 반영했지만, 또 다른 흥행 축인 "AI로 다 되는 시대의 편집 없는 진짜"는 반영되지 않음. AI 음악 추천·요약·일러스트는 모두 자동 생성으로만 서술되어 있고, 제목 추천만 "선택 가능"이라 명시됨.
- **선택지 예시**:
    - a) 모든 AI 기능을 사용자가 켜고 끌 수 있는 선택 옵션으로 통일
    - b) 지금처럼 자동 생성 유지 (AI 감성 케어가 서비스 정체성이므로 문제 없다고 판단)
- **내 결정**: b

## 🟢 사소한 누락

### 5. 알림 스케줄링 인프라가 1단계 로드맵 설명에 안 드러남

- **위치**: TECHNICAL POINT(BE&DB) / ROADMAP 1단계
- **문제**: AI 질문 프롬프트(1단계, MVP)는 매일 푸시 알림이 필요한데, "정기 알림 발송 스케줄링 인프라" 항목이 그룹 체크인(2단계) 맥락으로만 읽혀 MVP 공수 산정에서 누락될 위험.
- **내 결정**: 로드맵 설명에 추가

---

### 6. "이어쓰기" 후 AI 생성물 재처리 정책 없음

- **위치**: CORE FEATURES 1번(원라인 모드 - 이어쓰기) / 4번(AI Integration)
- **문제**: 원라인으로 시작해 AI가 제목/이미지를 생성한 뒤, 사용자가 이어쓰기로 내용을 크게 바꾸면 기존 AI 생성물을 재생성할지 유지할지 정의 안 됨.
- **내 결정**: 이미지 생성을 옵션으로 선택하게 함. 생성 버튼을 누를 시 이미지 생성. 이렇게 되면 이어쓰기 후 이미지 생성을 누르면 새로운 이미지가 생성되어서 재처리 정책이 필요없게 됨.

### 7. 최종적인 화면 구성 예상
    화면구성 : 
        1. 일기 모아져 있는 메인화면 (기존의 기획을 따름)
        2. 한달을 AI가 요약해주는 화면 (기존의 기획을 따름)
        3. 공통 질문을 통해 답변을 공유하는 Q&A 화면 (인스타 Q&A or 셋로그 느낌)
        4. 채팅 기능 (그룹별 채팅, 셋로그 처럼 채팅 기능을 넣기)
## 최종 정리: 
- 메인 기능은 일기 다이어리 기능 (기존의 기획)
- 부가 기능으로 인스타 스토리에 QnA 기능처럼 그룹 멤버들과 소통 및 일상 공유가 가능한 기능 (셋로그 일부 차용)
    - 그룹 멤버들이 특정 시간대에 공통된 질문을 올리면, 그룹에 속한 유저들에게 푸시 알람으로 질문이 올라왔다고 알리고 유저들은 실시간으로 질문에 답변할 수 있음 (실시간 일상 공유로 소속감 부여)
    - 질문을 올리면서 사진 첨부 가능 (텍스트 위주로 인한 피로감 해소)
    - 질문은 AI가 아닌 그룹 멤버들이 자율적으로 전송 가능하도록 함. 다만 AI가 질문 추천을 해주는 기능 추가 예정(이 시간대에는 이런 질문을 추천 예: 12:00에는 '점심 뭐 먹었니', '오늘 학식 뭐니' 등등)
    - 인스타 스토리처럼 질문들은 48시간이 지나면 삭제됨. 다만 원하는 질문들은 저장이 가능함. (Soft Delete를 사용)
- 월별, 또는 주별로 지난 일기들을 요약해주는 화면 구성
- 그룹 멤버들과 채팅할 수 있는 그룹별 채팅 기능 (1:1 채팅은 제외)
